# Codex Pets

这里保存可用于 Codex／ChatGPT Work 宠物系统的自定义动画宠物资源。

## 目录约定

```text
pets/<作品-slug>/<角色-slug>/
├─ README.md          # 角色说明与使用信息
├─ pet.json           # 机器可读的宠物清单
├─ ATTRIBUTION.md     # 来源、署名与权利说明
├─ assets/            # 可直接使用的发布资源
├─ previews/          # 动画和静态预览
└─ qa/                # 验证摘要与检查图
```
