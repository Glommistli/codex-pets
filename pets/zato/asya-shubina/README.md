# Asya Shubina — Z.A.T.O.

以《Z.A.T.O. // I Love the World and Everything In It》的 Asya Shubina（Ася Шубина）为原型制作的 ChatGPT Work v2 动画宠物。

![全部状态预览](previews/all-states.gif)

思考／工作状态固定为一个清晰的托腮思考姿势，人物本体在六帧中保持不动；右上角依次出现小点、膨胀的思考气泡和问号，问号停留两帧后随气泡收回。

![思考动作固定帧率预览](previews/working-cadence.gif)

## 发布资源

- `assets/spritesheet-v2.png`：可直接导入的 v2 精灵表。
- `pet.json`：尺寸、帧数、状态顺序、校验值及稳定 pet ID。
- `previews/`：全部状态、单状态、视线方向和固定帧率思考动作预览。
- `qa/`：设计合同、结构校验、思考节奏校验、方向检查与质量报告。

精灵表尺寸为 1536 × 2288 px，采用 8 × 11 网格和 192 × 208 px 单元格，包含 9 个标准动画状态与 16 个观察方向。

新图集已更新到原有稳定宠物 ID；Asya 仍是当前激活宠物。线上图集经服务端重新编码后与本地发布文件的像素完全一致。
