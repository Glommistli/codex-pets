# 玛丽娜·卡普兰 — Z.A.T.O.

以《Z.A.T.O. // I Love the World and Everything In It》的角色玛丽娜·卡普兰（Marina Kaplan）为原型制作的 Codex／ChatGPT Work v2 动画宠物。

![全部状态预览](previews/all-states.gif)

## 动作设计

本版本没有给所有状态套用同一种轻微摇摆，而是依据玛丽娜温和、机敏、略带克制俏皮的性格分别设计：

- `waving`：采用原作截图中的前伸碰拳作为招呼动作。
- `failed`：笑容僵住、侧眼、揉鼻梁、短暂泄气后恢复。
- `waiting`：叉腰、点靴、前倾摊手，带有不咄咄逼人的“怎么样？”语气。
- `working`：搓手、指尖计数、点太阳穴、握拳作出决定。
- `reviewing`：抱臂观察、怀疑侧目、最后认可点头。
- `idle`、左右奔跑和跳跃分别保留自然呼吸、利落步态与轻快起落。

所有动作使用待机条作为唯一人物尺度基准，以同一个源图到单元格缩放率提取。跑步时的前倾、跳跃时的下蹲和腾空只改变姿势与位置，不再整个人物随状态放大或缩小；非跳跃动作共用脚底基线，跳跃落地也回到同一基线。

## 发布资源

- `assets/spritesheet-v2.png`：可直接导入的 v2 精灵表。
- `pet.json`：尺寸、帧数、状态顺序、文件校验值及已上传宠物 ID。
- `previews/`：全部状态、视线方向、跳跃动作和跨状态尺度检查的动态预览。
- `qa/`：最终联系表、方向检查图、尺度测量和验证摘要。
